# with onnx2tf, and test-runs the result with TensorFlow's interpreter.

# onnx, onnxruntime, transformers) to older versions; the other tools work with
# them. Tested on Windows and Python 3.12 with tensorflow 2.21, onnx2tf 2.6.9,
# numpy 2.2, onnx 1.20, onnxruntime 1.26 and transformers 4.57.
